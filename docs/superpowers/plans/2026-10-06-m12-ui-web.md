# UI Web e API RESTful Desacoplada (Marco M12) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implementar a Interface Web moderna e a API RESTful desacoplada do TranslaterAny (v1.3), com gerenciamento de biblioteca, fila de jobs com suporte a pausa e retomada, streaming SSE em tempo real, editor de memórias da série, grafo interativo de pipeline plugável e central de configurações.

**Architecture:** Arquitetura desacoplada em 3 camadas: API RESTful JSON pura (`/api/v1/`) e SSE broadcaster no backend FastAPI, camada de serviços reutilizável (`Service Layer`) e camada de visualização em SSR Jinja2 + HTMX 2.x com Tailwind CSS embutido (100% offline). Execução do pipeline em thread worker isolada com controle de estado atômico (`PENDING`, `RUNNING`, `PAUSED`, `COMPLETED`, `FAILED`, `CANCELLED`).

**Tech Stack:** Python 3.14, FastAPI, Uvicorn, Jinja2, HTMX 2.x, Tailwind CSS (standalone minificado), Pydantic, Typer, pytest.

**Spec:** `docs/superpowers/specs/2026-10-06-m12-ui-web-design.md`

## Global Constraints

- Python 3.14 compatível (`requires-python = ">=3.14"`).
- Zero dependências de Node.js, npm ou bundlers externos; assets estáticos embutidos localmente no pacote.
- Desacoplamento estrito: todas as ações de dados e jobs devem ter endpoints REST JSON correspondentes em `/api/v1/`.
- Execução isolada em background para não bloquear o event loop do FastAPI.
- A pausa e retomada de jobs devem ocorrer em fronteiras seguras de etapas sem corromper artefatos ou hashes SHA-256 no `manifest.json`.
- Zero regressões: manter os 746 testes existentes passando com 100% de sucesso.

## Review Focus

- Fila e concorrência: garantir que apenas 1 job pesado de pipeline execute por vez na GPU/CPU, enfileirando os demais com status `pending`.
- Mecânica de pausa: garantir que o token de pausa suspenda o worker sem abortar a etapa em andamento e retome de onde parou.
- Autonomia offline: certificar que os templates não façam requisições para CDNs externas, servindo HTMX e Tailwind de arquivos locais.
- Validação de configurações: garantir que qualquer alteração de `config.toml` ou `series.toml` via web passe pela validação do Pydantic antes de gravar no disco.
- Fechamento gracioso: garantir que encerrar o servidor FastAPI com SIGINT/Ctrl+C finalize ou aborte o worker de jobs de forma limpa.
